## SCR-01 로그인

**URL** `/login`

### 화면 레이아웃

```
┌─────────────────────────────────────────┐
│                                         │
│           영업 일일 보고 시스템            │
│                                         │
│  ┌─────────────────────────────────┐    │
│  │  이메일                          │    │
│  └─────────────────────────────────┘    │
│  ┌─────────────────────────────────┐    │
│  │  비밀번호                        │    │
│  └─────────────────────────────────┘    │
│                                         │
│  [ 로그인 ]                              │
│                                         │
└─────────────────────────────────────────┘
```

### 입력 항목

| 항목 | 타입 | 필수 | 유효성 검사 |
|---|---|---|---|
| 이메일 | text | Y | 이메일 형식 |
| 비밀번호 | password | Y | 최소 8자 |

### 동작

| 이벤트 | 동작 |
|---|---|
| [로그인] 클릭 | 인증 성공 시 대시보드(SCR-02)로 이동, 실패 시 오류 메시지 표시 |
| 엔터 키 | 로그인 실행 |

## SCR-02 대시보드 (홈)

**URL** `/dashboard`

### 화면 레이아웃

```
┌─────────────────────────────────────────────────────────────┐
│  [로고]  영업 일일 보고      🔔 알림(3)    홍길동 ▼          │
├──────────┬──────────────────────────────────────────────────┤
│          │                                                   │
│  대시보드  │   안녕하세요, 홍길동님                             │
│  보고서   │   오늘 날짜: 2026-05-01                           │
│  고객관리  │                                                   │
│  사원관리  │  ┌──────────────┐  ┌──────────────┐             │
│  (관리자) │  │ 오늘 보고서    │  │ 이번 달 방문   │             │
│           │  │   미제출      │  │    12건       │             │
│           │  └──────────────┘  └──────────────┘             │

│           │  ─── 최근 보고서 ───────────────────────────     │

│           │  2026-04-30  홍길동  확인완료  [보기]             │
│           │  2026-04-29  홍길동  확인완료  [보기]             │
│           │                                                   │
│           │  ─── 최근 댓글 (상급자 기준) ──────────────────   │
│           │  홍길동 · 2026-05-01 · "다음 방문 일정 확인 요망" │
│           │                                                   │

```

### 구성 요소

| 영역 | 설명 | 권한 |
|---|---|---|
| 오늘 보고서 미제출 수 | 본인 미제출 여부 표시 (상급자는 팀 전체 미제출 수) | 전체 |
| 이번 달 방문 건수 | 본인의 이번 달 방문 기록 총 건수 | 영업 사원 |
| 최근 보고서 목록 | 최근 5건, [보기] 클릭 시 상세(SCR-05)로 이동 | 전체 |
| 최근 댓글 | 최근 달린 댓글 5건 (상급자만 표시) | 관리자·상급자 |
| 오늘 보고서 작성 버튼 | 오늘 보고서가 없을 때 표시 | 영업 사원 |

## SCR-03 일일 보고서 목록

**URL** `/reports`

### 화면 레이아웃

```
┌─────────────────────────────────────────────────────────────┐
│  일일 보고서 목록                        [ + 오늘 보고서 작성 ] │
├─────────────────────────────────────────────────────────────┤
│  기간: [2026-04-01] ~ [2026-05-01]   사원: [전체 ▼]  [검색]  │
│  (사원 필터는 상급자에게만 표시)                               │
├────────┬──────────┬──────────┬────────┬──────────┬──────────┤
│ 날짜   │ 작성자   │ 방문 건수 │ 상태   │ 제출일시  │ 작업     │
├────────┼──────────┼──────────┼────────┼──────────┼──────────┤
│ 05-01  │ 홍길동   │ 3건      │ 제출   │ 18:00    │ [보기]   │
│ 04-30  │ 홍길동   │ 2건      │ 확인   │ 17:45    │ [보기]   │
│ 04-29  │ 홍길동   │ 4건      │ 확인   │ 17:30    │ [보기]   │
│ 04-28  │ 홍길동   │ -        │ 초안   │ -        │ [수정]   │
├────────┴──────────┴──────────┴────────┴──────────┴──────────┤
│  ◀ 이전   1  2  3   다음 ▶                                   │
└─────────────────────────────────────────────────────────────┘
```

### 필터 항목

| 항목 | 타입 | 기본값 | 비고 |
|---|---|---|---|
| 시작일 | date | 이번 달 1일 | |
| 종료일 | date | 오늘 | |
| 사원 선택 | select | 전체 | 상급자만 표시 |

### 상태 배지 색상

| 상태 | 표시명 | 색상 |
|---|---|---|
| draft | 초안 | 회색 |
| submitted | 제출 | 파랑 |
| reviewed | 확인 | 초록 |

### 동작

| 이벤트 | 동작 |
|---|---|
| [보기] 클릭 | 보고서 상세(SCR-05)로 이동 |
| [수정] 클릭 | 보고서 작성/수정(SCR-04)으로 이동 |
| [+ 오늘 보고서 작성] 클릭 | 오늘 날짜로 SCR-04 이동 (이미 있으면 버튼 비활성) |

## SCR-04 일일 보고서 작성/수정

**URL** `/reports/new` / `/reports/:id/edit`  
**접근 권한** 영업 사원 (본인 보고서, 초안 상태만)

### 화면 레이아웃

```
┌─────────────────────────────────────────────────────────────┐
│  일일 보고서 작성 · 2026-05-01                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ■ 고객 방문 기록                          [ + 행 추가 ]     │
│  ┌──────┬──────────┬──────┬────────────┬──────────┬──────┐  │
│  │ No   │ 고객명   │ 방문 │ 방문 목적  │ 상담 내용 │ 결과 │  │
│  │      │         │ 유형  │           │           │      │  │
│  ├──────┼──────────┼──────┼────────────┼──────────┼──────┤  │
│  │ 1    │[고객선택▼]│[유형▼]│ (입력)    │ (입력)   │(입력)│  │
│  │      │          │      │            │          │ [삭제]│ │
│  ├──────┼──────────┼──────┼────────────┼──────────┼──────┤  │
│  │ 2    │[고객선택▼]│[유형▼]│ (입력)    │ (입력)   │(입력)│  │
│  │      │          │      │            │          │ [삭제]│ │
│  └──────┴──────────┴──────┴────────────┴──────────┴──────┘  │
│                                                             │
│  ■ 다음 액션 (각 행별 입력란 - 방문 기록 테이블 하위)          │
│                                                             │
│  ■ 과제·상담 (Problem)                                      │
│  ┌─────────────────────────────────────────────────────┐   │
│  │                                                     │   │
│  │  (자유 입력 텍스트)                                  │   │
│  │                                                     │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  ■ 내일 계획 (Plan)                                         │
│  ┌─────────────────────────────────────────────────────┐   │
│  │                                                     │   │
│  │  (자유 입력 텍스트)                                  │   │
│  │                                                     │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│                       [ 임시저장 ]   [ 제출 ]               │
└─────────────────────────────────────────────────────────────┘
```

### 고객 방문 기록 행 입력 항목

| 항목 | 타입 | 필수 | 설명 |
|---|---|---|---|
| 고객명 | select (검색형) | Y | 고객 마스터에서 선택, 검색 가능 |
| 방문 유형 | select | Y | 직접방문 / 전화 / 화상 / 이메일 |
| 방문 목적 | text | Y | 단문 입력 |
| 상담 내용 | textarea | Y | 방문 시 상담한 내용 |
| 결과 | textarea | N | 상담 결과 |
| 다음 액션 | textarea | N | 후속 조치 사항 |
| 방문 시각 | time | N | 방문한 시각 |

### 기타 입력 항목

| 항목 | 타입 | 필수 | 설명 |
|---|---|---|---|
| 과제·상담 (Problem) | textarea | N | 현재 과제, 문제, 상담 필요 사항 |
| 내일 계획 (Plan) | textarea | N | 내일 수행할 업무 계획 |

### 동작

| 이벤트 | 동작 |
|---|---|
| [+ 행 추가] 클릭 | 고객 방문 기록 행 1개 추가 |
| [삭제] 클릭 | 해당 방문 기록 행 삭제 (확인 팝업) |
| [임시저장] 클릭 | 상태 draft로 저장, 페이지 유지 |
| [제출] 클릭 | 유효성 검사 후 상태 submitted로 변경, 목록(SCR-03)으로 이동 |
| 제출 확인 팝업 | "제출하면 수정이 불가합니다. 제출하시겠습니까?" 확인/취소 |


### 구성 요소

| 영역 | 설명 | 권한 |
|---|---|---|
| 고객 방문 기록 테이블 | 읽기 전용 | 전체 |
| 과제·상담 (Problem) | 읽기 전용 텍스트 + 댓글 영역 | 전체 |
| 내일 계획 (Plan) | 읽기 전용 텍스트 + 댓글 영역 | 전체 |
| 댓글 입력창 | Problem / Plan 각각에 댓글 등록 | 상급자·관리자 |
| [수정] 버튼 | 초안 상태이고 본인 보고서일 때만 표시 | 영업 사원 |
| [확인 완료] 버튼 | submitted 상태일 때 표시 | 상급자·관리자 |

### 동작

| 이벤트 | 동작 |
|---|---|
| [수정] 클릭 | SCR-04 수정 화면으로 이동 |
| [댓글 등록] 클릭 | 댓글 저장 후 화면 갱신, 작성자에게 알림 발송 |
| [확인 완료] 클릭 | 상태를 reviewed로 변경, 작성자에게 알림 발송 |

## SCR-10 알림 목록

**URL** `/notifications`

### 화면 레이아웃

```
┌─────────────────────────────────────────────────────────────┐
│  알림                                        [ 전체 읽음 처리 ] │
├─────────────────────────────────────────────────────────────┤
│  🔵  김팀장님이 2026-05-01 보고서에 댓글을 남겼습니다.          │
│      (Problem) "견적 마감일 공유해 주세요."   05-01 18:30     │
│      [보고서 보기]                                           │
├─────────────────────────────────────────────────────────────┤
│  ⚪  2026-04-30 보고서가 확인 완료되었습니다.   04-30 19:00    │
│      [보고서 보기]                                           │
├─────────────────────────────────────────────────────────────┤
│  ⚪  오늘 보고서가 아직 제출되지 않았습니다.    05-01 17:00    │
│      [보고서 작성하기]                                       │
└─────────────────────────────────────────────────────────────┘
```

### 알림 유형

| 유형 | 트리거 | 링크 |
|---|---|---|
| comment | 상급자가 댓글 등록 | 해당 보고서 상세 (SCR-05) |
| reviewed | 상급자가 확인 완료 처리 | 해당 보고서 상세 (SCR-05) |
| reminder | 매일 오후 5시 미제출 알림 | 보고서 작성 (SCR-04) |

### 동작

| 이벤트 | 동작 |
|---|---|
| 알림 항목 클릭 | 읽음 처리 후 해당 링크로 이동 |
| [전체 읽음 처리] 클릭 | 전체 알림 읽음 상태로 변경 |
