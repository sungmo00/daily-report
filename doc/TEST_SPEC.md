# 영업 일일 보고 시스템 테스트 명세서

## 테스트 개요

### 테스트 범위

| 테스트 유형 | 설명 |
|---|---|
| 단위 테스트 (Unit Test) | 개별 함수·모듈의 로직 검증 |
| 통합 테스트 (Integration Test) | API 엔드포인트 및 DB 연동 검증 |
| E2E 테스트 (End-to-End Test) | 사용자 시나리오 기반 전체 흐름 검증 |

### 테스트 환경

| 항목 | 내용 |
|---|---|
| 테스트 DB | 프로덕션과 분리된 전용 테스트 DB |
| 인증 | 테스트용 JWT 토큰 픽스처 사용 |
| 데이터 초기화 | 각 테스트 케이스 실행 전 DB 초기화 |

### 테스트 계정 픽스처

| 계정 | 역할 | 이메일 |
|---|---|---|
| 홍길동 | rep (영업 사원) | hong@test.com |
| 이영업 | rep (영업 사원) | lee@test.com |
| 김팀장 | manager (상급자) | kim@test.com |
| 박관리 | admin (관리자) | park@test.com |

## 1. 인증 (Auth)

### TC-AUTH-001 로그인 성공

| 항목 | 내용 |
|---|---|
| **테스트 ID** | TC-AUTH-001 |
| **테스트명** | 유효한 이메일·비밀번호로 로그인 성공 |
| **유형** | 통합 |
| **선행 조건** | 영업 사원 계정 존재 (hong@test.com) |

**입력값**

- HTTP 200
- `data.accessToken` 존재
- `data.user.role` = `"rep"`
